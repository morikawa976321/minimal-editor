# キー操作一覧

現行の採用版（ネイティブ版）。2026-10-18時点。ブラウザ版は `ブラウザ版.vbs` で保持。

## メモの操作

新規メモの名前は「無題」。本文の先頭行（最初の改行まで）が自動で名前になり、先頭行の編集にも追従する。画面上の折返しは改行に数えない。先頭行が空・空白だけなら「無題」のままで、二行目以降は名前に使わない。前後の空白・制御文字は名前から除く。自動名は先頭行全体を使い、一覧では画面幅に合わせて省略表示する。

Ctrl+Mで手動改名したメモは、以後の本文編集でもその名前を維持する。既存の手動名も保持する。

| キー | 操作 | 条件 |
| --- | --- | --- |
| Ctrl+N | 新規メモを作成して開く | タイトル入力中は無効。作成前に現在の本文を保存 |
| Ctrl+P | 中央のメモ一覧を開く／閉じる | タイトル入力中も閉じられる |
| Ctrl+Shift+P | アーカイブモーダルを開く／閉じる | メモ一覧とは別に表示 |
| ↑ / ↓ | 一覧の選択を移動 | 一覧を開いている間。移動だけでは本文は切り替わらない |
| Enter | 選択したメモを開く | メモ一覧内。アーカイブモーダルでは選択したメモを復元して開き、モーダルを閉じる |
| Esc | 一覧を閉じる | 本文は切り替えず、編集位置に戻る |
| Ctrl+M | 選択したメモのタイトルを編集 | 通常一覧内のメモが対象。開いていないメモも変更可能 |
| Delete | 選択したメモをアーカイブ | 通常一覧内。確認なし。長押しの繰り返しは無効 |
| Ctrl+Z | 直前のアーカイブを取り消す | 一覧を開き、取消トーストが出ている間。タイトル入力中は文字のUndo |
| Tab / Shift+Tab | 一覧・取消ボタンの間でフォーカスを移動 | 取消ボタンは表示中のみ |
| Enter / Space | フォーカス中の取消ボタンを押す | ボタンにフォーカスがあるとき |

取消トーストは通常8秒で消える。ポインターを重ねている間や取消ボタンにフォーカスがある間は期限を止める。連続してアーカイブした場合、取消対象は直前の1件。

期限後は Ctrl+Shift+P → ↑/↓ で復元したいメモを選び Enter。アーカイブを解除した上で、そのメモを開く。通常のメモ一覧にはアーカイブを表示しない。

メモ一覧を閉じる操作は Esc／Ctrl+P。アーカイブモーダルは Esc／Ctrl+Shift+P。相手側のショートカットを押すとその一覧へ切り替わる。×ボタンはなく、モーダル外をクリックしても閉じない。タイトル入力中も両キーで閉じ、未確定のタイトル変更は取り消す。保存・切替などの処理中やIME変換中は閉じる操作を受け付けない。

## タイトル入力中

| キー | 操作 |
| --- | --- |
| Enter | タイトルを保存。保存失敗後は再試行 |
| Esc | 未確定のタイトル変更を取り消してモーダルを閉じる |
| Tab / Shift+Tab | タイトル入力欄にフォーカスを保つ |
| Ctrl+Z | タイトルの文字編集を元に戻す（入力欄の標準操作） |

IME変換中のキーは、アプリのショートカットとして処理しない。

選択の強調は灰色。IME変換中通知の間は本文と同じ暗い背景を使う。OS全体の配色は変更しない。2026-10-26に本人が実利用で青背景の解消を確認済み。

## 本文の編集

本文は標準のテキスト入力欄。Ctrl+A（全選択）、Ctrl+C（コピー）、Ctrl+X（切り取り）、Ctrl+V（貼り付け）、Ctrl+Z（文字編集のUndo）、矢印やHome/End、PageUp/PageDownなどの標準操作が使える。本文のCtrl+Zはアーカイブの取消には使わない。

先頭の表示行で↑を押すと行頭へ、最終の表示行で↓を押すと行末へ移動する。折り返しを含む表示行で判定する。選択範囲がある場合・Shift/Ctrl/Altを伴う場合・IME変換中は標準動作を維持する。タイトル入力欄も同じ。

アプリ内の警告音は無効。移動・削除などができない場合も音を鳴らさない。エラーが起きた場合の表示は維持する。

保存は別スレッドで自動実行し、保存中も本文を入力できる。終了は最後の保存成功後。手動保存用のショートカットは設けていない。

ホイールはWindowsのスクロール行数設定に従う。一時表示のバーをドラッグしても移動できる。全文が1画面に収まるときはバーを表示しない。一覧を閉じると、元の選択範囲とスクロール位置へ戻る。

## スクロールバーにフォーカスがあるとき

以下は保持しているブラウザ版の操作。現在のネイティブ版の独自スクロールバーにはTabで移る経路がない。本文側の矢印・PageUp/PageDown等は使える。

## Gitとメモの保存先

ツールのコード・文書はGit管理し、privateのoriginへpushする。メモはローカルの data/ に保存し、本文・タイトル台帳・バックアップ・履歴・復元コピーをまとめてGit対象外としている。data/ で追跡するのは空ディレクトリ維持用の .gitkeep だけ。

.work/ もGit対象外。ブラウザーの専用プロファイルや試験用データを含む。Gitへのpushはメモ本文のバックアップにはならない。
