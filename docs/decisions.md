## astra の判断 · 起動と比較ページ

`Minimal Editor.lnk` をスタートメニューに1個だけ置き、比較ページを Edge app ウィンドウで開く。`比較を開く.cmd` も同じ入口。A/B/C のボタンはローカルサーバーへ認証付きで起動を依頼する。常駐サービスや自動起動登録、独自 URL スキームは追加しない。

比較HTMLは1ファイルで、選択はクリックだけ。「一番いい」、各組の「どちらも問題ない」、「全部問題ない」、「全部合わない」、「保留」、致命的な問題の5分類を備える。結果を1ブロックにし、本人が「結果をコピー」を押した場合だけクリップボードへ書く。自動テストはクリップボードを変更していない。判断カードは折りたたみ、日常のエディター画面には説明を置かない。

**依頼との制約差**: 標準ブラウザーでダブルクリックした HTML だけから、停止中の Node や native exe を任意に起動することはできない。生成済み `比較.html` は補助サーバー稼働中ならダブルクリック→各案をクリックで起動できる（テスト済み）。PC 再起動後はスタートメニューまたは cmd の入口を使う。常時自動起動・関連付けの変更で解決する案は、この試作のために環境変更を増やすので採らなかった。冷起動も HTML 一枚だけで完結したと報告しない。

**覆る条件**: この入口自体が本人の負担になった場合。方式確定後は1個の既存ショートカットを採用版へ直結する。
